# Employee Management System

This is an Angular 22 practice project.

Purpose:

Learn Angular 22 deeply before integrating a .NET 10 backend.

Current Phase:

Frontend only.

No backend exists.

Use mock data only.

Technology:

- Angular 22
- Standalone Components
- Bootstrap 5
- TypeScript
- Signals
- Reactive Forms

Architecture

Follow Feature First architecture.

Folders

app/
    core/
    shared/
    features/
    layouts/
    models/
    store/
    utils/

Rules

Always:

- Keep components small.
- Follow SOLID principles.
- Use Angular Signals whenever appropriate.
- Use @if, @for and @switch.
- Use typed Reactive Forms.
- Use lazy loading.
- Prefer composition over duplication.
- Write reusable components.
- Use strongly typed interfaces.
- Explain every architectural decision.
- Never use deprecated Angular APIs.

Coding Style

- Clean Architecture
- Enterprise standards
- Production ready
- Readable code
- Consistent naming

When generating code:

1. Explain why.
2. Explain Angular concepts.
3. Mention interview questions.
4. Suggest improvements.

Never:

- Generate unnecessary code.
- Ignore existing project structure.
- Introduce breaking changes without explanation.

Future

This frontend will later connect to a .NET 10 Web API.
